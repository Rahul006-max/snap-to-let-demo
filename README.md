# SnapToLet Website Redesign

A visual and UX redesign of **snaptolet.com**, inspired by the design principles of **Wise (wise.com)**.

## Highlights
- **Giant, Confident Typography**: Fluid display headers using heavy `Plus Jakarta Sans` with tight tracking and leading.
- **Bold Color Blocks & Rhythm**: Alternating soft off-white (`#F4F7F4`), cinema neutral, and deep forest green (`#0A3425`) sections.
- **The Tool is the Hero**: Dedicated, high-contrast To-Let Board Generator console with real-time live signboard preview, dynamic QR code generation, and multi-format exports (PDF, JPG, PNG).
- **100% Verbatim Content**: All text, translations (29 Indian languages + English), and business logic preserved identically from the original website.
- **Original Assets**: Full resolution brand illustrations, character artwork, and app store badges.

## Tech Stack
- Semantic HTML5, Modern CSS (Custom Properties / Design Tokens), Vanilla JavaScript
- Vendor Libraries: `qrcode.min.js`, `jspdf.umd.min.js`
- Mobile-first, fully responsive at 375px, 768px, and 1440px.
